Geyser

Powered by Geyser. Standalone gateways translate Bedrock UDP to a Java TCP server. Not affiliated with GeyserMC or Mojang. Geyser is not shipped with the manager; it downloads when you create a gateway. ViaProxy is optional and is never downloaded unless you choose compatibility mode.

New Geyser Standalone gateway

The gateway stays stopped until you start it. Online authentication is recommended.

Floodgate must be installed on the Java server, and Geyser must share the same 16-byte key.pem. For a local Java server, Start downloads Floodgate into mods/ or plugins/ if it is missing, copies the key, and restarts that Java server. For a remote server, install Floodgate yourself and copy the gateway key.pem into its Floodgate folder.
